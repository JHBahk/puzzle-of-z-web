GitHub 연결

비공개 저장소의 데이터를 읽고 기록하려면 이 저장소에 Contents 읽기·쓰기 권한이 있는 Fine-grained token이 필요합니다. 토큰은 서버로 보내지 않고 GitHub API에 직접 사용합니다. 이 탭 세션에서만 보관합니다.

NEXT와 이전은 진행 위치만 저장하고 공격으로 기록하지 않습니다. 실종으로 보고하면 해당 좌표는 즉시 목록에서 제외되고 순번이 자동 정리됩니다. 공격 완료·실종은 GitHub 저장 후 다음 좌표로 이동합니다.

원하는 웹 순번으로 이동

Y구간 수색 목록

숫자 0~9로 수색 구간을 선택합니다. 각 구간은 Y 20단위로 구분하고, 구간 안에서는 X 오름차순으로 표시합니다. 목록을 보는 것만으로 수색 완료 처리하지 않습니다.

새 농장 등록 / 기존 농장 갱신

같은 서버에서 정확히 일치하는 닉네임이 하나라면 기존 ID의 좌표 이동으로 자동 갱신합니다. 가까운 좌표도 중복을 확인해 갱신하며, 다른 닉네임의 이웃 농장은 별개로 등록합니다. 신규 농장은 다음 코스 생성 시 반영됩니다.

생산건물 자원량 입력 (선택)

창고 자원과 나무는 제외. 미입력 수치는 추측하지 않습니다.

자동 게임 조작 기능이 없는 개인용 도구입니다. 이 페이지에 인증 토큰을 넣기 전 출처를 확인하고, 토큰을 다른 사람과 공유하지 마세요. GitHub 저장에 실패하면 완료로 표시하지 않습니다.
