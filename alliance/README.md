# BAM 연맹원 좌표 관리 (비밀번호·Cloudflare 없는 독립 페이지)

## 웹 주소
- **공개 조회:** https://jhbahk.github.io/puzzle-of-z-web/alliance/
- **좌상단 노란색 B 로고 클릭 → 관리자 페이지:** https://jhbahk.github.io/puzzle-of-z-web/alliance/admin.html
- 관리자 페이지에 로그인이나 PIN은 없다. **관리자 페이지 주소 자체는 공개되어 있으므로 누구나 접속할 수 있다.**
- 기존 폐지줍기 웹 (`/index.html`) 및 `targets.json`과 완전히 분리된 화면·데이터이다.

## 현재 방식의 한계 (중요)
Cloudflare/외부 DB/비밀번호가 필요 없도록 제거했기 때문에 **수정 내용은 현재 기기의 브라우저 localStorage에만 저장**된다.
- 관리자 페이지에서 저장하자마자 같은 기기의 공개 조회 화면에는 반영된다.
- **다른 기기·다른 연맹원에게는 자동 반영되지 않는다.**
- 브라우저 데이터를 삭제하거나 다른 기기로 변경하면 로컬 수정본이 사라질 수 있다.
- 다른 사람 모두에게 공유하려면 **관리자 페이지 → JSON 내보내기**로 `BAM_연맹_좌표_100자리.json` 파일을 저장해서 프로젝트 사용자에게 보내고, GitHub `alliance/data.json`에 반영해야 한다. 이 ChatGPT 프로젝트에 JSON을 첨부하면 GitHub 연결을 통해 공개 데이터에 반영할 수 있다.
- 원본과 로컬 저장본 중 수정 시각이 더 최신인 쪽을 우선한다. GitHub 공개 데이터가 나중에 갱신되면 새 공개 데이터를 읽는다.
- JSON 가져오기를 통해 다른 기기의 백업본을 현재 기기에서 확인·수정할 수 있다.
- 인증이 없어도 문제가 없는 구조(로컬 전용)이므로 입력값을 수정해도 원본 GitHub 파일이 변경되는 일은 없다.

## 관리자 이용 방법
1. 조회 웹 상단의 **노란색 B 로고**를 탭해서 관리자 페이지 이동 (로그인 없음).
2. 지도에서 번호를 탭하거나 목록에서 선택.
3. **선택한 자리 수정하기** 버튼에서 닉네임/X/Y 입력.
4. 같은 기기에서 즉시 적용되고 로컬 저장. 2×2 건물, 산, 전초 충돌과 연맹 영역 검사.
5. 전체 연맹원에게 공유할 때는 **JSON 내보내기** 파일을 GitHub 관리 담당자에게 전달한다.
6. 공개 배치도 SVG는 **지도 저장 ↓** 버튼으로 다운로드한다.

## 좌표 고정 기준 (V2 100개)
- 기준 JSON: `alliance/data.json`. 지휘센터 **100개**; 위치번호 1~100은 고정한다.
- 보루 (299,535), 음향 (297,533), 강철 (301,533).
- 창고 (313,537), 병원 (315,535) — 정확히 X−2 적용한 버전.
- 전초기지 1 (287,535), 2 (298,546), 3 (298,524), 4 (309,535). 전초5 없음.
- 고정 산 장애물 (299,531), (286,538), (300,548). (318,538)은 미확정 산으로 배치 검증에서 제외.
- 닉네임 3~4글자 권장, 24자까지 입력. 표시할 때 길면 앞 9글자만 표시.
- 실제 지형과 황무지 경계는 게임 화면 확인 필요.

## 파일
- `alliance/index.html`: 공개 조회
- `alliance/admin.html`: 로컬 관리자 편집
- `alliance/app.js`: 양쪽 화면 공통 동적 SVG 지도·검색·로컬 편집·JSON 백업
- `alliance/style.css`: 양쪽 화면 공통 스타일
- `alliance/data.json`: 전체 공유용 기준 100개 좌표
- Cloudflare Worker, D1, 관리자 비밀번호, API 토큰, 자동 배포 워크플로우는 사용하지 않는다.

## 데이터 영속성 주의
서버/로그인 없는 구조에서 일반 연맹원의 브라우저가 자동으로 GitHub에 기록할 권한은 없다. 단순히 B를 숨은 관리자 입구로 만드는 것은 편집 권한 보안이 아니며, 여기서는 기기 로컬 편집 도구로만 사용한다. 연맹 전체 동기화·여러 기기에서 자동 편집을 원하면 나중에 반드시 별도의 인증·저장 수단을 추가해야 한다.
